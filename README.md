# Видовдан — предлог редизајна

Неслужбени предлог редизајна магазина [vidovdan.org](https://vidovdan.org), направљен
као идеја коју је могуће показати власницима сајта.

Прототип је статичан — обичан HTML, CSS и JavaScript, без оквира, без библиотека
и без иједног спољног мрежног захтева.

## Уживо

**https://vidovdan-predlog-redizajna.vercel.app**

Линк је јаван — отвара се без налога, на рачунару и на телефону.
Деплој повлачи садржај из гране `main` овог репозиторијума у току build-а,
па се објављено освежава новим деплојом након `git push`.

## Покретање

Фонтови се учитавају преко `@font-face`, што захтева HTTP (не ради преко `file://`):

```bash
python3 -m http.server 8000
# отворити http://localhost:8000
```

## Дизајн систем

Правац: **„камен и хартија"** — боје узете из српског средњовековног сликарства,
рендероване са уздржаношћу штампаног магазина.

| Улога | Боја |
| --- | --- |
| Пергамент (подлога) | `#F2EDE3` |
| Мастило (текст) | `#191512` |
| Оксблуд (акценат) | `#8C1F2F` |
| Лапис | `#1E3A5C` |
| Злато | `#A8801F` |

Типографија:

- **Prata** — заглавље магазина, бројеви, издвојени цитати
- **Vollkorn** — наслови и текст чланака
- **Golos Text** — навигација, ознаке, метаподаци

Све три породице имају пун ћирилични скуп знакова.

## Шта прототип ради

- **Ћирилица ⇄ латиница** — право пресловљавање у прегледачу, укључујући двознаке
  (`ЉУБАВ → LJUBAV`, `Његош → Njegoš`). Избор се памти у `localStorage`.
  Редакција и даље пише само једном, ћирилицом.
- **Ноћно читање** — засебна палета, не инвертована светла тема. Прати подешавање
  уређаја, може се променити ручно.
- **Мера за читање** — текст чланка до 68 знакова у реду, прород 1,72.
- **Приступачност** — контраст изнад 4,5:1, видљив фокус за тастатуру, семантички
  наслови, поштовање `prefers-reduced-motion`. Циљ је WCAG 2.1 AA.
- **Без спољних захтева** — фонтови су локални, нема CDN-а ни аналитике трећих страна.

## Структура кода

```
assets/
  css/
    fonts.css      @font-face дефиниције за локалне фонтове
    vidovdan.css   цео дизајн систем (променљиве, компоненте, стране)
  fonts/           woff2, подскупови: латиница, ћирилица (+ проширени)
  js/
    image-slot.js  <image-slot> — места за фотографије у прототипу
    support.js     писмо, тема, навигација, претрага, напредак читања
```

### `<image-slot>`

Прототип нема праве фотографије, па сваки `<image-slot>` црта детерминистичку
дуотон плочу. Иста комбинација атрибута увек даје исту слику.

```html
<image-slot tone="oxblood" seed="101" ratio="16/10" label="Фотографија"></image-slot>
<image-slot tone="ink" seed="7" round></image-slot>
```

Тонови: `oxblood`, `lapis`, `gold`, `ink`, `olive`, `plum`.
При преласку на прави садржај, свака оваква ознака се замењује обичним `<img>`.
