# Фонтови

Приложени `.woff2` фајлови су подскупови — исечени на знакове које овај сајт
стварно користи (српска ћирилица, латиница и српски дијакритици).

| Фонт | Аутор | Лиценца |
| --- | --- | --- |
| Prata | Cyreal | SIL Open Font License 1.1 |
| Vollkorn | Friedrich Althausen | SIL Open Font License 1.1 |
| Golos Text | Paratype | SIL Open Font License 1.1 |

Пун текст лиценце: https://scripts.sil.org/OFL

Фонтови су послужени локално да сајт не би слао ниједан захтев ка
серверима трећих страна.
